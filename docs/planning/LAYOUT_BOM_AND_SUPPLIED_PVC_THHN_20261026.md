# Layout-specific BOM and supplied PVC / THHN prices

Implemented 26 October 2026. No test files added and no test suite run.

## User workflow

- Project information is a compact table: Client, Designer, Location and Layout. **Details** opens the relevant contact, service and date information; empty optional fields are omitted.
- New project/client intake offers **Lighting layout, Power layout, Data layout**. A project default lives in the existing assignment JSON. Each plan's BOM can override it using the existing append-only material-selection API.
- Choosing a layout filters known device families and wire products. Lighting shows luminaires and switches; Power shows power outlets/distribution devices; Data shows data/communications devices. Unclassified detections remain reviewable, rather than receiving an invented class.
- Explicitly attached routes belonging wholly to another load category are omitted from that layout's live takeoff. Panels and boxes do not by themselves identify a route as Power. Unknown/shared connections remain available for review. Geometry is never deleted or regenerated by category selection.
- The BOM and new BOM exports group rows by Lighting, Power and Data. Existing untyped plans remain readable until assigned a layout; unknown/shared rows have a separate **Layout not set** heading so they cannot appear to belong to the preceding category. Service entrances belong to Power, but do not classify an attached lighting circuit as a Power load. Historical estimate downloads retain their captured identities and prices.
- Lighting and Power default to the supplied **Phelps Dodge THHN stranded 3.5 mm², PHP 33/metre**. The supplied **150 m roll, PHP 4,950**, is a separate selectable purchase product. Data retains a data-cable default and compatible explicit selections.
- **Conductors per route** fills only missing conductor counts. THHN is a single-conductor product: its price sheet supplies no circuit conductor count, so no multiplier is invented. A missing count has a clickable action to the exact count field. Known per-wire counts take priority. Multicore data cable route metres are not multiplied.

Price history, source originals, saved geometry, explicit compatible selections and historical estimates are preserved. No new database table or column was required for this change.

## Username security

- Usernames normalize surrounding whitespace and ASCII case at validation boundaries, without trimming passwords.
- Creation, Admin edits and self-service credential edits check normalized usernames, including legacy mixed-case records.
- The existing unique database index remains the final concurrent-write guard. A uniqueness collision rolls back the attempted write and returns HTTP 409 with a clear username message, rather than an uncaught database error or an orphaned account.
- Sign-in refuses ambiguous legacy case-colliding identities; it does not merge or select an arbitrary account.
